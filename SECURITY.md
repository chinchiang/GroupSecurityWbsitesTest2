# Repository security policy

## Reporting a vulnerability in this repository

Do not open a public issue containing exploit details, credentials, customer information, or internal system data. Use the private GitHub vulnerability-reporting feature after the repository owner enables and verifies it. Until then, contact the repository owner through an independently verified internal channel.

This document covers the **source repository** only. It is not the product PSIRT/CVD policy and does not provide a public product-vulnerability intake address. The example `security.txt` file contains placeholders by design.

## Supported versions

There is no production release yet. Only the current reviewed milestone is eligible for security fixes.

## Scope reminders

- The site is a static synthetic-data demo.
- It has no authentication, backend, uploads, connectors, or persistent case storage.
- The persona selector is not authorization.
- Do not submit live incidents through this demo.
