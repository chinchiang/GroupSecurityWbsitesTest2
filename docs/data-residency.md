# Data residency and jurisdiction

Target partitions are Global, EU, Taiwan, and China. Production data and management planes are region-aware; cross-region transfer requires documented purpose, approved legal basis, minimum fields, classification, recipient, retention, and audit evidence.

There is no unrestricted global search index. A production search request carries verified user and resource context, executes against permitted regional sources, and returns only policy-filtered snippets. Cache, export, AI retrieval, observability, backup, and support access follow the same boundary.

Milestone 01 contains synthetic records only. Region labels demonstrate policy context; they do not prove data localization or compliance.
